## Реализация

### Сумма через reduce

Функция `sum_with_reduce` использует `functools.reduce` и `operator.add`
с начальным значением `0`. Она проходит по входу один раз, принимая
список, кортеж, генератор или другой итерируемый объект.

Принимаются `int` и конечные `float`; `bool`, строки, NaN и бесконечности
отклоняются. Пустая последовательность даёт `0`. В CLI сначала проверяется
возможность прочитать `int`, и только затем — `float`, поэтому целые числа
не преобразуются в вещественные без необходимости. Для `float` действует
обычная двоичная арифметика Python; округление денежных сумм здесь не
предусмотрено. Неконечный результат сложения также отклоняется.

```python
from lab4_tasks import sum_with_reduce

print(sum_with_reduce(number for number in range(5)))  # 10
```

### Генератор Фибоначчи

`fibonacci_numbers()` выдаёт `0, 1, 1, 2, 3, ...` через `yield`. Новое число
вычисляется при следующем запросе, рекурсии и списка всех прошлых значений
нет. Генератор бесконечный: потребитель выбирает нужное количество чисел.

```python
from itertools import islice
from lab4_tasks import fibonacci_numbers

numbers = fibonacci_numbers()
print(list(islice(numbers, 5)))  # [0, 1, 1, 2, 3]
print(next(numbers))            # 5: продолжение того же потока
```

### Случайные числа в диапазоне

`random_numbers(lower, upper, count, seed=...)` — конечный генератор целых
чисел. Диапазон включает обе границы; равные границы допускаются.
Границы должны быть целыми, количество — неотрицательным целым. Значения
`bool` отклоняются. При `count=0` последовательность пуста.

Случайные генераторы в проекте используют собственные экземпляры
`random.Random`, поэтому не меняют глобальное состояние `random`.
Одинаковый целочисленный `seed` воспроизводит выборку в той же версии
Python. Без `seed` генератор инициализируется автоматически.

Поскольку это генераторные функции, проверка их аргументов выполняется
при первом `next()` или начале перебора, а не при создании объекта.

### Каррирование

`curry` преобразует вызов `f(a, b, c)` в последовательность вызовов
`curry(f)(a)(b)(c)`. Пока аргументов недостаточно, возвращается новая
функция-замыкание. Частичные функции независимы и допускают повторное
использование:

```python
from lab4_tasks import curry

multiply = curry(lambda a, b, c: a * b * c)
times_two = multiply(2)
print(times_two(3)(4))            # 24
print(times_two(5)(6))            # 60
print(multiply(2, 3)(4))          # 24
print(multiply(a=2)(b=3, c=4))    # 24
```

`inspect.signature` проверяет аргументы на каждом шаге. Поддерживаются
позиционные и именованные параметры, включая positional-only и
keyword-only. `functools.wraps` сохраняет имя и документацию функции.

Вызов выполняется сразу, как только переданы все обязательные параметры.
Поэтому необязательные параметры нужно передать до этого момента или на
том же шаге. Например, для `f(a, b=10)` вызов `curry(f)(2)` сразу использует
`b=10`, а `curry(f)(b=3)(a=2)` позволяет указать другое значение.
Функции с `*args` и `**kwargs` отклоняются: автоматический момент окончания
накопления аргументов для них неоднозначен. Пустой шаг при недостающих
обязательных аргументах вызывает `TypeError`.

### Бесконечные случайные данные

`random_records(seed=...)` выдаёт новые словари следующего вида:

```json
{"id": 1, "category": "C", "value": 14}
```

`id` возрастает с 1, `category` выбирается из `A`, `B`, `C`, `value` — целое
число от 0 до 100 включительно. Каждый словарь независим от остальных.
Поток не имеет фиксированной длины; после выборки его можно продолжить.

```python
from itertools import islice
from lab4_tasks import random_records

records = random_records(seed=42)
first_three = list(islice(records, 3))
print(first_three)
print(next(records)["id"])  # 4
```

Бесконечные потоки следует ограничивать через `islice` или собственное
условие остановки. Не следует передавать весь поток в `list()`.

## Тесты

Из корня проекта:

```bash
python -m unittest discover -s tests -t . -v
```

Из другого каталога:

```text
python -m unittest discover -s "/полный/путь/к/mtp-lab4-variant3/tests" -t "/полный/путь/к/mtp-lab4-variant3" -v
```

`tests/__init__.py` оформляет тесты как пакет, а `-t` задаёт корень импорта.
Проверяются пустые и некорректные входы, границы диапазона, продолжение
генераторов, воспроизводимость `seed`, независимость состояния и словарей,
ветвление каррированных функций, аргументы по умолчанию и ошибки вызова.
CLI запускается отдельными процессами из временного каталога; тесты
проверяют вывод, JSON-строки, коды завершения и `stderr`.
